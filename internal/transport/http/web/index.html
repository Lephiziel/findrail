Keyboard shortcuts

Press / to focus Search, or Ctrl+K (⌘+K on macOS). These shortcuts are inactive while editing text or while a dialog is open. Use Tab and Shift+Tab to move between controls; focus a Preview button and press Enter to open that result.

Evidence collection

Manage saved evidence, notes, and collection exports.

Saved evidence keeps the historical indexed text. Forgetting a source or removing a document also deletes its collection citations and notes (logical deletion, not secure erasure). Exported plaintext cannot be recalled.

Import evidence bundle

Choose a JSON bundle. It contains the selected citations and notes; source aliases must be explicitly mapped to sources in this index.

Remove source?

The local searchable index and associated saved citations/notes will be removed. Original files are not changed; deletion is logical, not forensic.
