# Findrail 0.1.0-alpha.5 release notes (prepared)

These notes describe the prepared alpha.5 contract, not a published release.
Until the owner authorizes publication, alpha.4 remains the current download.

## What's new

- Passage windows show matching text with surrounding indexed context; PDF
  citations retain original page numbers. DOCX files do not have Word page
  numbers in Findrail.
- Search results can be paged. Presets preserve search configuration; **Apply**
  loads a preset but does not run a search.
- Evidence bundles export selected evidence for review and verification.
- Frozen sources can be transferred through the Sources UI. A snapshot contains
  indexed text and metadata, not a complete backup of original files or data.
- Diagnostics and integrity reporting make index/source health inspectable.

The preview displays indexed text. The original viewer opens the current original
file, which may have changed since indexing. This is an unsigned alpha; automated
coverage applies only to recorded environments and synthetic fixtures.
