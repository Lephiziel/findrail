# ADR 0004: open core capabilities and optional model services

Status: accepted for this project.

License repository code under Apache-2.0. Keep core local retrieval and connector
interfaces independently usable. Model-based retrieval is optional and must
document provider data flows. Do not introduce required hosted credentials for
basic local search.

Possible operated offerings can charge for infrastructure and support. Changes
to governance or licensing require public discussion and respect existing
licenses; contributor code is not silently relicensed.
