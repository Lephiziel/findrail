# Findrail: локальная альфа

Findrail — открытое приложение на Go, которое ищет нужные слова в выбранных
папках с заметками, исходным кодом и текстовыми PDF. Оно показывает найденный
фрагмент, источник, сохранённый текст документа и страницу PDF. Пока приложение
запущено, изменения в папках обновляют индекс автоматически. Всё работает
локально без AI-подписки и загрузки документов в облако.

## Что уже работает

SQLite FTS5 и ранжирование; UTF-8 текст, Markdown, код и текстовые PDF; несколько
папок и фильтр источника; CLI и JSON; локальный веб-интерфейс с предпросмотром;
автообновление; статус ошибок; поиск во время индексации. Неудачный обход
сохраняет прежние результаты. Удаление источника не меняет исходные файлы.

## Установка

Скачай архив своей ОС из [Releases](https://github.com/Lephiziel/findrail/releases)
и распакуй. Go не нужен. Бинарники альфы не подписаны; macOS может потребовать
явного разрешения в настройках безопасности.

```bash
./findrail demo
# После демо: Ctrl+C, затем запуск своей папки
./findrail start /path/to/notes
```

Эти команды доступны начиная с `0.1.0-alpha.2`. Демо содержит три вымышленных
документа: введи `idempotency` и открой PDF на странице 2. Рабочая папка демо
временная, её путь печатается в терминале. При обычной остановке она удаляется;
основной индекс используется только командой `start`.

На Windows используй `.\findrail.exe` и путь к своей папке. Открой
http://127.0.0.1:7766. Нажми Preview для просмотра текста. Адрес оригинала
копируется кнопкой Copy location: браузеры ограничивают открытие `file:`.

Держи `start` запущенным для автообновления. `watch` обновляет индекс без
веб-сервера. `serve --no-sync` показывает только сохранённый индекс. Параметры
ставятся до папки или запроса; один и тот же `--data-dir` используется во всех
командах.

## Ограничения

Это версия для тестирования. Сканированные PDF требуют OCR, которого пока нет.
Для PDF действуют ограничения размера, числа страниц, извлечённого текста и
времени обработки. Индекс содержит незашифрованный текст и пути. Встроенной
аналитики нет. После обновления с первой версии переиндексируй папку, чтобы
включить PDF; старые источники сохраняют прежнюю политику.

GitHub, другие сервисы, DOCX, семантический поиск, desktop launcher и MCP пока
запланированы. Потенциал большого проекта — в общем поисковом ядре, форматах,
коннекторах и клиентах; спрос проверяем на реальных задачах пользователей.
