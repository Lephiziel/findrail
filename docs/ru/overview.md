# Findrail: локальная альфа

Findrail ищет слова в выбранных папках с заметками, кодом, текстовыми PDF и
Word DOCX. Показывает найденный фрагмент, сохранённый текст документа,
источник и страницу PDF. Индекс содержит обычный незашифрованный текст и пути;
локальный сценарий работает без аккаунта, AI-модели и загрузки документов.

**Последняя опубликованная версия — [0.1.0-alpha.5](https://github.com/Lephiziel/findrail/releases/tag/v0.1.0-alpha.5).**
[Результаты проверки выпуска](../release-alpha5-verification.md) ·
[Что изменилось](../release-notes-alpha5.md).

## Что уже работает

Поиск, предпросмотр и страницы текстовых PDF, DOCX body text, обновление папок,
управление источниками, Advanced-запросы и фильтры, публичные GitHub-снимки
с ручным обновлением, переносимые снимки, отчёты индексации и `.findrailignore`.
Есть CLI, локальный веб-интерфейс, read-only MCP, отдельный VS Code-клиент,
Literal `evaluate` и экспериментальный connector kit.

Alpha.5 добавляет окна фрагментов длинных документов, страницы результатов,
пресеты поиска и перенос цитат с заметками через evidence bundles.
В Sources можно явно экспортировать, проверить и импортировать снимок текста
по пути на компьютере с Findrail. Desktop launcher с установкой в меню ОС,
открытие оригиналов по разрешению и именованные коллекции остаются доступны.
В `start` / desktop можно явно сохранить цитаты, заметки и порядок, а затем
восстановить их после перезапуска с тем же каталогом данных.

## Установка alpha.5

Скачай архив своей ОС/архитектуры со страницы
[выпуска](https://github.com/Lephiziel/findrail/releases/tag/v0.1.0-alpha.5) и
[SHA256SUMS.txt](https://github.com/Lephiziel/findrail/releases/download/v0.1.0-alpha.5/SHA256SUMS.txt),
проверь соответствующий SHA256 и распакуй. Go, Python и внешний сервер базы
данных не нужны. Для macOS требуется версия 13 или новее. Архивы не подписаны;
на macOS может понадобиться разрешение только для этого приложения в Privacy
& Security. Перед обновлением останови Findrail и скопируй весь каталог данных.

Запусти из распакованного каталога:

```bash
# Linux
./findrail-desktop

# macOS
open Findrail.app
```

```powershell
# Windows PowerShell
.\findrail-desktop.exe
```

Для установки в меню используй per-user скрипт из `launcher/linux/`,
`launcher/macos/` или `launcher/windows/`: точные команды и удаление описаны
в [INSTALL.txt](../../build/package/INSTALL.txt). Повторный запуск открывает
уже работающее приложение. Закрытие вкладки оставляет его запущенным;
**Quit Findrail** завершает процесс. Desktop выбирает свободный loopback-порт.

Новый индекс пустой: в **Sources → Add folder** укажи абсолютный путь к папке
на этом компьютере. Найди слово, открой **Preview**, проверь фрагмент и страницу
PDF. У DOCX нет номеров страниц. Добавь цитаты и заметку в именованную коллекцию
и нажми **Save**; экспорт Markdown сохраняется отдельно. Для проверки на
отдельных данных запусти `findrail-desktop --data-dir ./findrail-test-data`
и используй этот путь при каждом запуске.

Открытие текущих оригиналов и содержащих папок включается явно через
`findrail-desktop --enable-originals` или `findrail start --enable-originals`.
Оно доступно для подходящих локальных файлов; PDF-viewer может открыть
документ на своей странице по умолчанию. Предпросмотр и сохранённые цитаты
показывают индексированный снимок, который может отличаться от текущего файла.

Обычный `./findrail start` (Windows: `.\findrail.exe start`) работает в
терминале, обычно на `http://127.0.0.1:7766`; Ctrl+C останавливает его.
Демо запускается через `./findrail demo` (Windows: `.\findrail.exe demo`):
запрос `idempotency` показывает три вымышленных документа и PDF на странице 2.
В `serve` / `demo` коллекция временная, только в текущей вкладке.
[Демо](../demo.md) · [Коллекции](../evidence-collections.md).

## Обновление и удаление

Alpha.5 использует схему 8; alpha.4 — схему 7, alpha.3 — схему 6. Перед
обновлением останови все процессы Findrail и скопируй **весь каталог данных**, включая WAL/SHM при
наличии, в отдельное место. Обратных миграций нет: alpha.4 нельзя запускать на
индексе схемы 8. Для отката восстанови полную резервную копию в другой каталог
и используй совместимую с ней версию. У старых источников из alpha.2 DOCX
выключен по умолчанию; настроенные политики сохраняются.

Удаление интеграции с меню не удаляет индекс. Останови приложение перед
удалением его файлов; каталог данных удаляй отдельно и только если он больше
не нужен. Исходные документы Findrail не меняет.
[Команды резервного копирования и отката](../../build/package/INSTALL.txt).

## Ограничения

OCR, семантического поиска, private GitHub, автоматических обновлений и
командной авторизации нет. DOCX извлекается как текст тела без вёрстки Word.
GitHub — публичные файлы, не issues/PR, с ручным обновлением. Portable snapshot
содержит индексированный текст и provenance; это не оригиналы и не полная
резервная копия базы. Сохранённые коллекции в portable source v1 не переносятся;
для выбранных цитат и заметок есть отдельные [evidence bundles](../evidence-bundles.md)
с явным сопоставлением источников и проверкой конфликтов.

`evaluate` сравнивает Literal-наборы путей: 1–100 кейсов, до 100 результатов
на кейс; incomplete — ошибка, mismatch даёт ненулевой код после полного отчёта.
[Поисковая оценка](../search-evaluation.md).

[VS Code VSIX](https://github.com/Lephiziel/findrail/releases/download/v0.1.0-alpha.5/findrail-readonly-0.1.0.vsix)
устанавливается отдельно и требует Findrail server/client API v1;
Marketplace и Open VSX не опубликованы. MCP-клиент может передавать полученные
фрагменты своему провайдеру модели. Connector kit экспериментальный.
Native CI и короткая проверка владельцем не означают ручную GUI-сертификацию
каждой ОС, браузера и редактора.
