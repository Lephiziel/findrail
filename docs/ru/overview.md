# Findrail: концепция и состояние

Findrail — приложение на Go для поиска по выбранным локальным папкам и, в
будущем, подключённым сервисам. Оно возвращает подходящие фрагменты с названием
источника и адресом оригинала. Индекс хранится у пользователя; обычный поиск
работает без AI-подписки. Интеграции и семантический поиск расширяют то же ядро.

## Уже реализовано

Индексация UTF-8 текста, Markdown и исходного кода; SQLite FTS5; ранжирование;
фрагменты совпадений; несколько папок; фильтрация по источнику; JSON; обновление
изменённых документов; удаление исчезнувших после полного обхода; сохранение
старого индекса при ошибке; CLI и небольшой локальный веб-интерфейс.

## Запланировано

PDF, DOCX, наблюдение за изменениями, GitHub, другие коннекторы, полноценный
просмотр документов, desktop launcher, семантический поиск и read-only MCP.
Каталоги будущих модулей содержат дизайн, а не фиктивную реализацию.

## Зачем это может стать большим продуктом

Общее ядро соединяет множество источников и клиентов. Контрибьюторы могут
добавлять форматы, коннекторы, языки поиска и интерфейсы. Главная гипотеза —
удобная установка, качественный поиск и понятный контроль своих данных.
Количество звёзд или доход эта архитектура не гарантирует.

## Запуск

```bash
go build -o bin/findrail ./cmd/findrail
./bin/findrail index --data-dir .findrail examples/notes
./bin/findrail search --data-dir .findrail "webhook"
./bin/findrail serve --data-dir .findrail
```

Открой http://127.0.0.1:7766. Сейчас адрес файла можно скопировать: браузер обычно
не разрешает открыть `file:` прямо из веб-страницы. PDF и облачные источники в
этой версии ещё не поддерживаются.
