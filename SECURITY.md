# Security reports

Findrail is a development foundation and should be evaluated with non-sensitive
test sources before wider adoption. Read `docs/data-handling.md` for actual trust
boundaries and current limitations.

Prefer GitHub private vulnerability reporting when it is enabled for this
repository. If it is unavailable, open a minimal issue requesting a private
contact channel. Do not include tokens, private source contents, or exploitable
details in a public report before coordination.

Include the affected commit, operating system, a synthetic reproduction, and
the observed boundary failure. Only the current development branch is being
maintained until a stable release policy is established.
