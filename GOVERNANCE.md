# Governance

Findrail is initially maintained by [Lephiziel](https://github.com/Lephiziel).
The maintainer reviews releases, architecture decisions, and contributor access.

Decisions affecting public contracts, data handling, or licensing are documented
in issues / discussions and architecture decision records. Contributors can
propose alternatives with concrete user needs and validation.

The repository is Apache-2.0. Core local retrieval is intended to remain usable
without mandatory hosted services. No launch metrics, sponsors, commercial
customers, or stable API guarantees are implied by this foundation.

As independent contributors join, document ownership areas and a path to
maintainer status. Resolve disagreements through evidence and respectful review.
