Findrail local alpha — https://github.com/Lephiziel/findrail

1. Extract the archive into a directory you own. Go is not required.
2. Open a terminal in the extracted directory.
3. Register a folder, then start the local search interface:

   Linux / macOS:
     ./findrail index /absolute/path/to/notes
     ./findrail serve

   Windows (PowerShell):
     .\findrail.exe index "C:\Users\YOU\Documents\Notes"
     .\findrail.exe serve

4. Open http://127.0.0.1:7766 in your browser.
   Keep the server running for automatic refresh. Ctrl+C stops it.

Keyword search, PDF text extraction and preview work without an AI account.
Scanned / image-only PDFs require OCR, which is not included. PDFs are limited
by default to 16 MiB, 500 pages and 1 MiB extracted text; extraction has a 10s
deadline. The child process has a soft Go memory target, not an OS sandbox.

On macOS, an unsigned downloaded binary may require opening Privacy & Security
and explicitly allowing this application according to your system policy.
These alpha binaries are not notarized or code-signed.

Use the same --data-dir DIR for index, search and serve if overriding defaults.
Sources from the original foundation remain text-only until you re-run index.
The index stores plaintext copies of extracted text. Select folders deliberately.
findrail forget SOURCE_ID removes that source from the index and leaves originals.

Options precede the folder or query. Run findrail --help for all commands.
No background daemon is installed; stopping serve or watch stops refresh.
To uninstall, stop Findrail and remove the executable. See docs/data-handling.md
in the repository for default index directories and optional index removal.
